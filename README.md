# Komşu Horlaması Milli Güvenlik Analizörü

> Duvarlar konuşmaz. Ama horlama konuşur. Bu yazılım o konuşmayı resmi dile çevirir.

Bu depo, komşunuzun gece çıkardığı sesleri **NATO üslubunda**, **aşırı ciddi** ve **tamamen gereksiz** bir istihbarat raporuna dönüştürür.

Bilimsel kanıt: yok.  
Resmiyet: fazla.  
İşe yararlık: şüpheli.  
Çalışır mı: evet, terminalde gerçekten çalışır.

## Kurulum

```bash
python3 analizor.py
```

Bağımlılık yoktur. Sadece Python 3 ve bir komşu yeterlidir. Komşu yoksa hayal edin; yazılım farkı anlamaz.

## Kullanım

1. Programı çalıştırın.
2. Komşu adını, katı ve horlama şiddetini girin.
3. Karşınıza resmi bir rapor çıksın.
4. Raporu kimseye göstermeyin. Özellikle komşuya.
